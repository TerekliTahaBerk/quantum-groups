# Archived submission material

Historical records of earlier publication plans for `quantum-group`. None of
this is needed to install, use or test the package, and none of it is part
of the release archives (see `.gitattributes`).

| Directory | Was | Status |
|---|---|---|
| [`jors/`](jors/) | `jors/` — *Journal of Open Research Software* software metapaper (submission #798, 28 Sep 2026) | Withdrawn by the author on 29 Sep 2026 after an APC waiver was declined |
| [`joss/`](joss/) | `paper/` — *Journal of Open Source Software* draft | Never submitted |

The current manuscript is the *SciPost Physics Codebases* userguide in
[`../scipost/`](../scipost/). The files here are unchanged apart from a
status note at the top of each README and checklist, so internal paths refer
to the layout before the move.
