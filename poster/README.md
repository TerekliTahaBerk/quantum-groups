# Thesis poster (historical)

Poster material prepared for the undergraduate thesis (in Turkish); kept for
provenance. It is not part of the Python package or the JOSS paper.

- `Quantum Grup Yapıları - YTU Poster.pptx/.pdf` — the Yıldız Technical
  University template version, built by `build_ytu_poster.py` (requires the
  university's poster template, which is not redistributed here).
- `Quantum Grup Yapıları - Poster.pptx/.pdf` — an earlier layout, built by
  `build_poster_v2.js` (Node, `pptxgenjs`). `_build_poster.py` edits the
  unzipped slide in `unpacked/` from an older iteration.
- `figures/`, `figures_ytu/`, `assets/`, `*.png`, `*.jpg` — images used by
  the posters.
